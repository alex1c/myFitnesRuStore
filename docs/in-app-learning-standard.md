# In-app learning standard

For apps with more than one obvious user scenario:

- Provide a discoverable **«Как пользоваться» / «Обучение»** section.
- Onboarding must **not** block the first launch (optional, dismissible).
- Learning content remains available later from settings/help.
- Explain **user scenarios**, not every control.
- Content is **offline** (no required WebView / remote articles).
- Do **not** place ads inside the help/learning flow.
- Describe **only real product features** and actual button labels.

This is a shared standard for our applications.
